# Zyrax

Cyberpunk overlay for upscaling (FSR/DLSS) and frame generation, inspired by Lossless Scaling.

## Features

- **FSR Support** - AMD FidelityFX Super Resolution integration
- **DLSS Support** - NVIDIA Deep Learning Super Sampling integration  
- **Frame Generation** - Advanced frame generation capabilities
- **Cyberpunk Overlay** - Sleek, neon-themed in-game overlay
- **Per-Game Profiles** - Custom settings for each application
- **Hotkeys** - Quick toggle and configuration
- **Multi-Platform** - Works on Windows and Linux

## Tech Stack

- [Tauri](https://tauri.app/) - Rust + Web frontend
- [Vite](https://vitejs.dev/) - Fast build tool
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](https://tailwindcss.com/) - Cyberpunk styling

## Development

```bash
# Install dependencies
bun install

# Run in development
bun run tauri dev

# Build
bun run tauri build
```
